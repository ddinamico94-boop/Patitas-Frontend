Diseña y genera una aplicación web moderna, responsive y profesional llamada “Patitas Tucumán”, basada en una plataforma comunitaria para reportar, encontrar y ayudar a animales perdidos, encontrados o en situación de calle en la provincia de Tucumán, Argentina. Objetivo Modernizar completamente la interfaz actual manteniendo la identidad visual de Patitas Tucumán, pero con una estética más actual, limpia, intuitiva y profesional. La aplicación debe transmitir confianza, empatía, comunidad y protección animal. La aplicación debe sentirse como un producto real listo para ser utilizado por ciudadanos, voluntarios y administradores. Identidad visual Utilizar una paleta inspirada en la aplicación actual: Fondo principal: crema/beige muy claro. Color principal: rojo terracota / rojo cálido. Texto principal: negro o gris carbón. Texto secundario: gris cálido. Blanco para tarjetas y formularios. Bordes oscuros suaves. Sombras discretas. Mantener elementos relacionados con animales, especialmente huellas de perro/gato, pero utilizarlos de manera moderna y sutil. Evitar que el diseño parezca infantil. Debe ser amigable pero profesional. Utilizar bordes redondeados, tarjetas modernas, iconografía consistente, buen espaciado, tipografía sans-serif moderna y una jerarquía visual clara. Estructura principal Crear una navegación superior moderna. En desktop: Logo + Patitas Tucumán a la izquierda. Navegación: Inicio Reportes Mapa Cómo ayudar A la derecha: botón “Ingresar” botón destacado “Reportar animal” En mobile utilizar una navegación compacta con menú hamburguesa y un botón flotante para “Reportar”. 1.
